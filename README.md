# Ekinotech Showcase

The repository is named `ekinotech-showcase`, but its current role is a minimal package consumer. It does not build the static showcase generated by Central, and it is not product documentation or production adoption evidence.

The static pages load `src/demos/shared/tokens.css`, which imports all token themes from `@ekinotech/design-tokens-ekinotech-showcase`. Vite bundles those package imports for deployment. The target does not keep a copied token CSS tree. Validation resolves all six supported CSS exports, checks their custom properties, and confirms that every page uses the shared CSS entry.

## Production-style Registry installation

Normal consumers install the published npm package from Central's project-level GitLab Package Registry:

```json
{
  "dependencies": {
    "@ekinotech/design-tokens-ekinotech-showcase": "<version>"
  }
}
```

The committed [.npmrc.example](.npmrc.example) points the `@ekinotech` scope to Central and contains only `${DESIGN_TOKENS_NPM_TOKEN}`. `.npmrc` is ignored.

```sh
cp .npmrc.example .npmrc
export DESIGN_TOKENS_NPM_TOKEN="<local-output-package-deploy-token>"
npm ci
```

See Central's [consumer integration guide](https://gitlab.ekino.com/ekino.vn/frontend-internal/design-token-central/-/blob/develop/docs/consumer-integration.md) for local and CI token setup.

## Optional pre-publication smoke test

Build the sample project package by following the [Central package guide](https://gitlab.ekino.com/ekino.vn/frontend-internal/design-token-central/-/blob/develop/docs/project-packages.md).

In this repository, set `EKN_PROJECT_PACKAGE_TARBALL` to the generated `.tgz` absolute path, then run:

```sh
npm ci
export EKN_PROJECT_PACKAGE_TARBALL="<absolute-path-to-generated-project-tgz>"
EKN_EXPECTED_PACKAGE_VERSION="0.1.0" \
npm run validate
```

This local `.tgz` path is only a pre-publication smoke test. Normal production installation uses the published npm package. The app does not copy generated files into this repository and contains no release, Storybook, or package-generation logic.
